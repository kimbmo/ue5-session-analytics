# v2 변경 사항 (v1 플레이테스트 3명 기반)

| v1 발견 | v2 변경 |
|---|---|
| 헤매는 사람에게 힌트가 안 나옴(E 연타가 타이머를 계속 리셋) | 힌트 타이머는 "실제 단계"에서만 리셋한다: 퍼즐 시작, 서랍 열기. 살펴보기, 다이얼, 오답으로는 리셋되지 않는다. 지연 시간은 30초/60초 그대로 |
| E를 눌러도 반응이 안 보임, E 연타 | 바라보는 부분 하이라이트. 대상이 있으면 크로스헤어가 노랗게 커지고, E를 누르면 튀어 오른다(빗나가면 빨강). E 사이 0.2초 쿨다운. 메시지는 더 크게, 배경 패널, 3초 |
| 같은 물감 두 번(노랑+노랑), 손잡이 오답 중복 기록 | 같은 물감을 연속으로 고르면 안내만 하고 오답으로 치지 않는다. 손잡이는 1초 쿨다운 |
| 힌트가 잘 안 보임 | 힌트 문구는 화면 상단 중앙에 큰 글씨로 4초. 힌트 빛 세기 2배(2.5 → 5) |
| P3 순서를 개수 순으로 읽음 | 금고 실루엣 안쪽을 각 그림의 바탕색으로 칠해 액자와 1:1로 연결 |
| P2 목표 색 연결이 약함 | 이젤 빈칸에 램프와 같은 초록 테두리 |
| 마우스가 빠름, 물체가 낮게 느껴짐 | 마우스 감도 1.0 → 0.5. 눈높이 160 → 152cm. 물감 받침대 60 → 80cm. 금고를 35cm 받침 위로 |
| P1을 찍어서 풂, 날짜를 비교하지 않음 | 날짜 라벨 확대(기획자 결정, 오답 쿨다운은 넣지 않음). 글자 6 → 10cm, 판 32×9 → 50×15cm(`LabelTextSize`로 조절). v1: 4m에서는 가장 가까운 라벨 하나만, 5.6m에서는 못 읽음 → v2: 방 왼쪽(4~5.6m)에서도 4개 모두 읽힘 |
