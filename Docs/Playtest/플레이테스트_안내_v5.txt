방탈출 프로토타입 플레이테스트 안내 (v5)
========================================

플레이 시간: 약 3~5분

1. 실행
   - zip 압축을 전부 풀고 SessionAnalyticsDemo.exe 를 실행하세요.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
   - 실행이 안 되거나 DLL 오류가 나면, 같은 폴더의 Engine\Extras\Redist\en-us\vc_redist.x64.exe 를 설치한 뒤 다시 실행해 주세요.
   - 게임 화면을 한 번 클릭하면 마우스가 잡힙니다.

2. 조작
   - WASD: 이동 / 마우스: 시점 / E: 조사·사용 / H: 힌트 / Esc: 메뉴
   - 방에서 탈출하는 게 목표예요.
   - 막히면 H를 눌러 힌트를 볼 수 있어요. 퍼즐마다 2단계까지 있고, 오른쪽 위에 몇 개 봤는지 나와요.
   - Esc를 누르면 게임이 멈추고 메뉴가 열려요. 마우스 감도도 여기서 바꿀 수 있어요.
   - 메모할 땐 Esc 메뉴를 열어 두세요. 메뉴가 열려 있는 동안은 시간이 흐르지 않아요.
   - 공략을 찾아보거나 다른 사람에게 묻지 말고 혼자 풀어 주세요.

3. 끝내기
   - 탈출하면 화면에 결과와 결과 파일 위치가 뜹니다. Esc 메뉴 → [게임 종료] → [예]로 끝내세요.
   - 중간에 포기해도 괜찮아요. Esc 메뉴에서 종료하면 거기까지 기록됩니다.
   - 결과를 보내기 전에는 다시 플레이하지 말아 주세요. (첫 플레이가 데이터예요)

4. 결과 보내기
   - 결과 파일(.csv)은 아래 폴더에 있어요. 탐색기 주소창에 그대로 붙여넣으면 열립니다.
       %LOCALAPPDATA%\SessionAnalyticsDemo\Saved\Analytics
   - 아래 세 가지 질문의 답도 같이 보내 주세요.
       1) 가장 막혔던 곳은 어디였나요?
       2) 가장 좋았던 순간은?
       3) "이건 알 수가 없었다" 싶은 단서가 있었나요?

게임 안 행동(퍼즐을 푼 시간, 시도 횟수, 힌트, 살펴본 물체, 메뉴 사용)만 기록되고 개인 정보는 기록하지 않아요.
도와주셔서 감사합니다!
