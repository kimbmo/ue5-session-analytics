## 발견

1. **P1은 날짜 단서 없이 전부 하나씩 들어서 풀었다.**
   - 3명 모두 정답 전에 액자를 2~3개 들었고, 정답 액자(2024.02)는 매번 마지막이었다.
   - 테스터 3은 메모를 P1을 푼 뒤에야 처음 읽었다.
   - 틀린 액자를 드는 데 비용이 없어서 날짜를 비교할 이유가 없다.
2. **힌트가 가장 필요한 사람에게 안 나왔다.**
   - 테스터 3은 P2에서 109초를 헤맸는데 P2 힌트는 0번이었다.
   - 같은 서랍·이젤을 반복해서 누른 것도 "진행"으로 인정돼 30초 타이머가 계속 초기화됐다.
   - 전체 힌트 사용: 0, 1, 1회.
3. **E를 연타했다. 눌러도 반응이 안 보였다는 뜻이다.**
   - 0.5초 안에 같은 대상을 다시 누른 횟수가 4~78번이었다.
   - 소감: "다 누르고 나서 반응이 없으니 뭐 할지 모름", "상호작용 시 글자 외에 명확한 포인트가 없음".
   - 연타 때문에 생긴 데이터 오염:
     - 같은 물감이 두 번 들어감 (`yellow+yellow`, `blue+blue`, 0.2초 간격)
     - 금고 손잡이 오답이 두 번씩 기록됨
4. **P3 순서 단서를 잘못 읽었다 (1/3).**
   - 테스터 1은 액자 크기 순이 아니라 개수 크기 순으로 넣었다: 7531, 1357(6531은 7을 6으로 잘못 셈).
   - 소감에서 가장 막힌 곳으로 꼽은 곳도 이 퍼즐이다.
5. **P2의 목표 색 연결이 약하다 (1/3).**
   - 테스터 3은 램프를 퍼즐 2 진행 64초째에야 처음 살펴봤다.
   - 그 뒤 같은 색 두 번, 빨강+노랑 같은 오답을 냈다.
6. **편의성 (소감)**
   - 마우스가 너무 빠르다.
   - 시선 높이와 물체 높이가 안 맞는다.
   - 힌트 빛이 잘 안 보인다.

## v2 개선안 (우선순위)

1. **힌트 타이머:** "진행"을 새 물체를 처음 살펴보거나 답을 입력할 때로만 인정한다. 같은 물체 반복은 진행으로 치지 않는다.
2. **상호작용 피드백:**
   - E를 누를 때마다 크로스헤어 반응을 주고, 바라보는 대상을 강조한다.
   - 메시지를 더 크게, 더 오래(3초) 보여준다.
   - 같은 물감을 연속으로 고를 수 없게 하고, 손잡이에 대기시간(쿨다운)을 둔다.
3. **P3 단서:** 실루엣을 각 그림의 바탕색으로 칠해 액자와 1:1로 연결한다.
4. **P2 단서:** 이젤 빈칸 테두리를 램프와 같은 초록으로 칠한다.
5. **P1:** 틀린 액자를 들면 짧은 대기를 둔다. 또는 액자를 하나 들 때마다 다른 액자가 잠깐 잠겨 무작위 시도에 비용을 준다. 날짜를 읽게 만드는 게 목표다.
6. **편의:** 마우스 감도 기본값을 내리고, 시선 높이를 조정한다. 힌트 빛 세기를 2배로 올린다.
